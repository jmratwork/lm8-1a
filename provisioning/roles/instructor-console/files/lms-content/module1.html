Module 1 — Scrutinising Sender Information

The sender field is the first and most important indicator of a phishing email. Attackers use several techniques to make malicious emails appear legitimate.

Display Name Spoofing

The display name (the friendly name shown in your email client) can be set to anything, regardless of the actual email address. Always check the raw email address, not just the display name.

Example: "IT Security Team" <attacker@malicious-domain.ru>
The display name looks legitimate; the domain does not.

Domain Look-alikes (Typosquatting)

Attackers register domains that visually resemble legitimate ones:

  • company-security.com vs company.com
  • companysecurity.com (no hyphen)
  • c0mpany.com (zero instead of letter o)
  • company.com.attacker.net (legitimate domain as subdomain)

Reply-To Mismatches

Even if the From address looks valid, the Reply-To header may point to a different domain controlled by the attacker. Always inspect email headers.
